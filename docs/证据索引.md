## 关于 `evidence/reference_run/`

这是 2026-10-30 那次真实运行（`t_664138d8_hiv1_darunavir_20261030-224808`）的 stage-3
运行目录**逐文件拷贝**，用来让 `tests/smoke_test.py` 在没有重跑对接的情况下也能真跑
`validate`（validate 会重读每个产物、重算 sha256）。

唯一的改动：`manifest.json`、`run_state.json`、`artifacts/01_intake.json`、
`normalized/*.csv` 里的**绝对路径字符串**被替换成 `<ORIGINAL_ROOT>` / `<HOME>` 占位符
（为了不把某台机器的目录结构带进交付包）。被 `validate` 校验的 `outputs/` 与 `schemas/`
**一个字节都没动**，所以 validate 通过这件事本身仍然有效。来源说明见
`cases/hiv1_1t3r_darunavir/evidence/PROVENANCE.md`。

## 数字的三种独立来源

同一个 RMSD 用了三种算法交叉验证（原始运行 `evidence/verify.json` 记录在
`docs/证据索引.md` 之外的历史证据里，结论如下）：

| 方法 | 数值 |
|---|---|
| RDKit `GetBestRMS`（对称性感知，流水线用） | 0.211 Å |
| `AlignMol` 单映射刚性叠合 | 0.211 Å |
| 不叠合、按图映射原地比对（两套坐标同处 1T3R 晶系） | 0.290 Å |

三者都远低于 2.0 Å 阈值，说明 0.211 不是叠合算法凑出来的。
